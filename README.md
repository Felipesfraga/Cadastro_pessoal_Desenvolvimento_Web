# Formulário de Cadastro Pessoal

Projeto desenvolvido em aula na Universidade Cruzeiro do Sul para praticar HTML, CSS e JavaScript na criação de um formulário de cadastro responsivo e interativo.

## 🔗 Demonstração
[Link da página online, se você ativar o GitHub Pages]

## 🚀 Funcionalidades
- Formulário de cadastro pessoal com campos como nome, e-mail e outros dados
- Validação dos campos com JavaScript
- Mensagens de erro e feedback visual para o usuário
- Layout responsivo, adaptado para celular e computador
- Transições suaves e destaque nos campos em foco

## 🛠️ Tecnologias
- **HTML5:** estrutura semântica da página
- **CSS3:** estilização com Flexbox/Grid e design responsivo
- **JavaScript:** validação e interatividade

## 📁 Estrutura do projeto
```
cadastro-pessoal/
├── index.html
├── style.css
└── script.js
```

## ▶️ Como executar
1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` no navegador

## 📚 O que aprendi
- Estruturar formulários com HTML5
- Criar layouts responsivos com Flexbox/Grid
- Validar dados e manipular o DOM com JavaScript
- Melhorar a experiência do usuário com feedback visual
